# Trusted v0.2 release command

The v0.2 tag/release publication fallback uses the control repository's trusted Issue Comment event path because that event is observable and can be triggered by an authenticated repository collaborator without an out-of-band local token.

Command:

`/ai-sdlc release version=0.2.0`

The workflow accepts only OWNER, MEMBER, or COLLABORATOR comments matching the exact command syntax. It reads `release/publish-v0.2.0.yaml`, requires its `source_baseline_commit`, verifies that commit is still an ancestor of the protected default branch, verifies `VERSION`, `release/v0.2.0.yaml`, and `CHANGELOG.md` have not changed since that baseline, checks out the exact baseline SHA, reruns `scripts/validate_release_readiness.py`, and creates `v0.2.0` plus the GitHub Release at that exact baseline.

For v0.2.0 the authorized release baseline remains `44e68d4ec6517135b0008ba4cf14fdb625f9481d`. Publication plumbing merged afterward is deliberately excluded from the tagged release content.
