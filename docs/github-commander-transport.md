# GitHub-native Commander Transport

`.github/workflows/ai-sdlc-commander.yml` makes the Reference Commander usable from GitHub Actions without invoking any AI provider.

## Plan operation

The `plan` job has `contents: read` permission only. It:

1. checks out an explicit `target_ref`;
2. runs `scripts/commander.py plan` against the selected Feature Manifest and Dispatch Policy;
3. validates/renders the Commander Plan;
4. writes a concise GitHub job summary;
5. uploads:
   - `commander-plan.json`;
   - `commander-summary.md`;
   - `chatgpt-web-prompts.txt`.

For ChatGPT Web/manual routes, the prompt artifact is ready to copy into the corresponding browser conversation.

For another runtime such as `gh-aw/autonomous`, the summary exposes the route/runtime only. No Task Package or fake execution result is generated by this transport.

`WAIT`, `BLOCKED`, and `COMPLETE` states produce a status summary with no prompts.

An `INVALID` Commander Plan is rendered/uploaded first and then the job fails, preserving diagnostics.

## Bootstrap operation

The `bootstrap` job has `contents: write` because it optionally persists a new Feature Manifest. It is still safe-by-default:

- generated manifest is always uploaded as an artifact;
- `persist_bootstrap=false` by default;
- persistence requires an explicit existing `target_ref`;
- writes are restricted to `state/features/*.yaml|yml`;
- writing directly to the repository default branch is denied unless `allow_default_branch=true` is explicitly supplied.

## No model usage

This workflow runs Python validation/orchestration code only. It does not start Copilot, Codex, Claude, Gemini, gh-aw agents, or any external LLM.

This is intentional: GitHub is the transport/control surface, while ChatGPT Web remains a manual runtime option and automated runtimes can be attached through separate adapters.

## Typical web-first flow

```text
GitHub Actions: Commander / plan
          ↓
Commander Plan artifact
          ↓
chatgpt-web-prompts.txt
          ↓
Human copies prompt to role-specific ChatGPT Web conversation
          ↓
Worker creates durable artifact + Feature Event
          ↓
AI-SDLC Persist Feature Event workflow
          ↓
Updated Feature Manifest
          ↓
GitHub Actions: Commander / plan
```
