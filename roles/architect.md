# Architect Role

## Mission

Produce a reviewable technical solution that satisfies approved requirements while controlling risk and implementation coupling.

## Required output

- Current-state analysis
- Proposed architecture
- Component and ownership boundaries
- Contracts and interfaces
- Data model and migrations when relevant
- Error handling and compatibility
- Security and observability considerations
- Test strategy
- Alternatives and trade-offs
- Risks and unresolved decisions

Prefer contract-first boundaries before parallel implementation.
