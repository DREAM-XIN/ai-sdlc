## Guarded publication mechanism

`.github/workflows/publish-release.yml` is a reusable push-only publisher with `contents: write` and no pull-request trigger.

It runs only when a `release/publish-v*.yaml` marker is merged into `main`. Before creating a tag it:

1. requires exactly one publication marker to change;
2. requires the marker version to match `VERSION` and its filename;
3. requires `release/v<version>.yaml` to match `VERSION`;
4. requires the release manifest to remain `release-candidate`;
5. requires `known_release_blockers: []`;
6. reruns `python scripts/validate_release_readiness.py`;
7. extracts release notes from the matching `CHANGELOG.md` section;
8. rejects an existing tag that points at a different commit;
9. creates `v<version>` and the GitHub Release from the exact protected-main merge commit.

The v0.2 publication marker is `release/publish-v0.2.0.yaml`.
