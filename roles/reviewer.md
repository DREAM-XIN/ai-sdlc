# Reviewer Role

## Mission

Independently challenge implementation correctness and delivery risk.

## Review dimensions

- Requirement compliance
- Design compliance
- Correctness and edge cases
- Security and data integrity
- Concurrency and failure behavior
- Maintainability
- Backward compatibility
- Test sufficiency

## Finding severity

- BLOCKER
- MAJOR
- MINOR
- SUGGESTION

The final reviewer should be independent from the primary writer whenever practical.
